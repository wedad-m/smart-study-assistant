
# Smart Study Assistant 📚🤖

Smart Study Assistant is an AI-powered project designed to help students study more efficiently by transforming lecture content into structured learning materials.

The project focuses on applying Natural Language Processing (NLP) techniques to analyze educational text and generate useful outputs such as keywords and exam-style questions.

---

## 🎯 Project Objectives
- Assist students in understanding lecture content more effectively
- Automate the generation of exam-style questions
- Apply AI and NLP concepts to real-world educational problems

---

## 🚀 Features
- Extracts important keywords from lecture text
- Generates Multiple Choice Questions (MCQs)
- Generates True / False questions
- Supports customizable question templates

---

## 🧠 Technologies Used
- Python
- Natural Language Processing (NLP)
- spaCy
- Regular Expressions
- Rule-based Question Generation
